### MVP 判決（Prompt 層）

| 問題 | 判決 |
|------|------|
| **可用性夠不夠？** | **有條件 YES** — Schema＋切段足以跑通產品流程；多數輸出「長得像空耳」。 |
| **可信度夠不夠？** | **NO（尚不足以自信上架多語）** — 禁令未跨模型內化；硬句天花板低；殘渣／兒化／語錯會讓使用者懷疑「這根本不像」。 |

**要自信上船需要先收斂（擇一或多）：**

1. **後處理硬閘**：掃掉孤立拉丁碎片、未許可「兒／爾」、非漢字腳本滲入；必要時拒收重試。  
2. **語種／模型閘門**：先開 Prompt 較穩的語對（如印尼、部分西語），硬例語種限模型或加人工覆核。  
3. **再收 Prompt 不如加驗收**：v1.2 已寫清禁令仍冒出 → 純加字效益遞減；應用驗收清單綁複測金標（逼丟／給薩加／瓦Den…）。  
4. **產品文案**：維持「僅供記憶」notice，並提供一鍵再生成，避免單次壞空耳鎖死信任。

→ 詳見 Canvas「v1.2 Prompt trust」區塊。
