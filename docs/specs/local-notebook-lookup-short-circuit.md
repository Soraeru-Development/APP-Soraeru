# 同字再查／本機短路（App）

架構決策以 [`docs/adr/0008-local-notebook-lookup-short-circuit.md`](../adr/0008-local-notebook-lookup-short-circuit.md) 為準；本機單字本 SoT 見 [`client-first-wordcards-sync.md`](./client-first-wordcards-sync.md)／ADR-0007。術語見 [`docs/glossary.md`](../glossary.md)。

## Problem Statement

學習者常會對「已經存過的字」再輸入或再 OCR。若每次都打分析，浪費額度、多等一輪，也與「本機已有完整單字卡」矛盾。產品需要：在 App 上用本機單字本辨識「同字已有卡」時，直接回到詳情複習；真正要新空耳或強制重跑 AI 時，才走分析／結果頁並計額度。

## Solution

- **查重範圍**：只查**本機單字本**（票 13 SoT）。**不**為短路去查雲端鏡像；同步會合後本機才會有他機卡。  
- **命中**：直接開該卡詳情；**無**確認框；**不**呼叫 analyze。  
- **未命中**：走既有分析路徑（含額度／登入門檻，見下）。  
- **短路鍵**：`OwnerUserId`＋`DetectedLanguage`＋`NormalizedText`（與存卡一致）。**必須有可用語言碼才短路**；語言未知時先分析（不得拿「無語言」去撞本機）。  
- **OCR**：裝置 OCR → 選字後，與手動輸入**同一套**短路。  
- **未登入**：可讀本機既有卡並短路開詳情；本機未命中則須登入才能分析。  
- **詳情「重新分析」**：明確入口進分析／結果頁；計額度；同字重產上限交給票 09（≤3）。  
- **結果頁 ForceRefresh／重產**：仍允許打 AI；上限同票 09。  
- **金標**：只影響分析管線（ADR-0001／0007）；**≠** 開卡短路。  
- **本切片**：只釘 **App**；Web 維持現況，之後另對齊。

## User Stories

1. As a 已登入學習者 on App, I want 手動輸入一個本機已存的字並直接進詳情, so that 複習不必再燒額度。  
2. As a 已登入學習者 on App, I want OCR 選出本機已存的字後同樣直接進詳情, so that 相機路徑與手動一致。  
3. As a 學習者, I want 短路命中時不要跳出「是否再開分析」確認框, so that 流程一步到位。  
4. As a 未登入學習者, I want 若本機已有該卡仍可短路開詳情, so that 離線／未登入也能複習。  
5. As a 未登入學習者, I want 本機未命中時被要求登入才能分析, so that 額度與帳號邊界不被繞過。  
6. As a 學習者, I want 語言尚未判定時不要被當成本機命中, so that 不會誤開別張卡或跳過必要分析。  
7. As a 學習者, I want 刪除某卡後再查同一字會重新分析, so that 刪除真的清掉「已有」狀態。  
8. As a 學習者, I want 同一短路鍵再存時覆寫該卡內容（與票 13 一致）, so that 不會長出重複卡。  
9. As a 學習者, I want 同一正規化字串在不同語言各有一張卡, so that 多語同形字不會互撞。  
10. As a 學習者, I want 在詳情頁按「重新分析」進入分析／結果流, so that 我能主動要新候選並接受計額度。  
11. As a 學習者, I want 結果頁仍可 ForceRefresh／重產且受同字 ≤3 上限約束, so that 探索空耳與防濫用並存（票 09）。  
12. As a 學習者, I want 金標命中只改變該次分析的空耳欄位、不代替本機開卡, so that 「策展庫有金標」不會被誤解成「我已經有單字卡」。  
13. As a Web 學習者, I want 本切片不強制改 Web 行為, so that App 可先交付短路；Web 之後另對齊。

## Implementation Decisions

- **查詢 SoT**：本機單字本倉儲（票 13）；短路查詢**禁止**打雲端鏡像／Notebook 鏡像 API 當查重。  
- **命中 UX**：導向既有詳情；略過 analyze 請求與結果頁。  
- **鍵**：與存卡相同三元組；缺語言碼 → 不短路 → 分析管線（含語種偵測）。  
- **登入門檻**：短路讀取沿用「未登入可唯讀本機」；分析寫入／呼叫仍需登入工作階段（與 ADR-0007 一致）。  
- **重新分析**：詳情提供明確 CTA；進入與一般分析相同的結果／重產語意；計額度；重產上限與票 09 對齊。  
- **邊界**：tombstone／已刪卡不參與命中；同鍵再存＝覆寫；不同 `DetectedLanguage`＝不同卡。  
- **金標**：仍只在 analyze 路徑（ADR-0001）；開卡短路不查已驗證空耳庫。  
- **表面範圍**：App only；Web 不在本切片改動。  
- **分層**：客戶端查本機＋導頁；分析／額度仍經共用 API（既有）；本切片不改 Server 擁有權模型。

## Testing Decisions

- 好測試：外部行為——本機命中不發 analyze、直接詳情；無語言不短路；刪卡後再查會分析；未登入命中可開詳情、未命中擋分析；不同語言兩張卡；重新分析會走路徑並可觀測計額意圖（與票 09 銜接）。  
- 優先 seams：本機查鍵純邏輯（或 ClientLogic 同等）＋導航／門檻；勿把「打了鏡像 API」當成功。  
- Prior art：票 13 本機倉儲／同鍵覆寫測試；票 09 重產上限（可後接）。

## Out of Scope

- Web 學習端短路對齊（另決策／票）。  
- 為短路去查雲端鏡像或已驗證空耳庫。  
- 命中時的確認對話框、合併多卡 UI。  
- 重產上限實作細節本體（票 09）。  
- 同步協定／LWW（票 14／15）；個人空耳編修 UI（票 16）。  
- iOS、完整 SRS。
